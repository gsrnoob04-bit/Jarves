1. GitHub pe naya repo banao, is folder ka sab kuch push karo (.github folder ke saath).
2. Repo > Actions > "Build APK" > Run workflow. 3-5 min baad Artifacts se Jarvis-APK download karo (zip ke andar app-debug.apk).
3. Install karo, app kholo: key daalo > 1) Permissions > 2) Accessibility ON > 3) Overlay > START.
4. Bolo: "Jarvis, WhatsApp kholo", "Jarvis, Rahul ko call karo", "Jarvis, torch on karo".
